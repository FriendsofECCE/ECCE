# Getting started

This chapter takes you from a package to a finished calculation. If you
only want to look at a structure or at existing results, you can stop after
the second page.

1. [Installation](installation.md): which packages to install, and what you
   see when you start ECCE for the first time.
2. [Looking at a file](looking-at-a-file.md): open a structure and look at
   the results of a calculation that ran elsewhere, with no compute machine
   and no code installed.
3. [Machines](machines.md): where calculations run, and how to tell ECCE
   where a code is installed.
4. [Your first calculation](first-calculation.md): a geometry optimisation
   of water with NWChem, from a new project to the results.
