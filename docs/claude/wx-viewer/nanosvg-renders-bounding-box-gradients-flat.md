The Builder's bond-order and geometry icons (`svg/bond-*.svg`, `svg/shape-*.svg`)
are ball-and-stick drawings with shaded spheres. A shared `radialGradient`
in the default objectBoundingBox units rendered as the last stop's flat colour
under `wxBitmapBundle::FromSVGFile`; one gradient per sphere with
`gradientUnits="userSpaceOnUse"` shades correctly. The files are generated by
`tools/screenshots/build_icons.py`, so change the drawing there and rerun it.

`ewxBitmap::colorIcon` loads them (the icon's own colours, unlike `svgIcon`,
which recolours a line icon to the text colour). `ShapeData::shapeToImage` and
`TBond::orderToImage` return the SVG path for every consumer: the drop-down
toolbars, the Build panel's `ImageDropDown`s and the mode toolbar buttons.
