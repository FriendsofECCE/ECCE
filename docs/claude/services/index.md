# Services: gateway, broker, data server, sessions

Read this before changing the data server, the broker, `Listen`, service startup, the `ecce-*` wrapper scripts or session end. Split out of CLAUDE.md 2026-10-04.

### The two background services ("the server")
Almost entirely new in this fork — not in the original app's docs.
`ecce` and the `ecce-<app>` wrappers (generated by `CMakeLists.txt`) start
what the deployment mode needs (GETTING_STARTED, "Deployment modes"):
- **Local (mode 1, the default on Linux):** a per-user `mosquitto` on a Unix
  socket and a per-user Apache data server, both non-root.
- **Local data folder** (`ECCE_LOCAL_DATA` or the Data folder preference;
  the default on macOS): the same per-user broker, no data server; the
  data lives in a local folder (FileEDSI).
- **Central server (mode 2, `-remote`):** one server account runs Apache and
  Mosquitto (TCP, authenticated) for everyone; clients start no data server
  and no local broker.
- **Shared system broker (mode 3, `siteconfig/SharedBroker`):**
  `ecce-broker.service`, a system service no user can stop.
