ECCE — archived, disabled computational-code menu registrations
==================================================================

These <ResourceType> blocks were cut out of ResourceDescriptor.xml
and ResourceDescriptorRxn.xml on 2026-08-30 (see issue #11 and the
related removal discussion) to stop AMICA, Gaussian-03, Gaussian-98,
and MetaDyn/Metadynamics from appearing as "New ... Calculation"
menu options. Kept here verbatim, not deleted, specifically so
re-enabling any of them later is a straightforward copy-paste.

Deliberately not a .xml file -- this whole file is a set of
unrelated top-level fragments, not one well-formed XML document,
so nothing should ever try to parse it directly.

The underlying .edml capability files, parser scripts, and app code
for these were NOT touched or removed -- only the menu-registration
XML blocks below. To re-enable a code:
  1. Copy its block back into the matching XML file at any
     top-level position (order among <ResourceType> siblings does
     not matter).
  2. For MetaDyn specifically, also restore the matching
     <Tool name="MetadynamicsEditor"> entry (archived below too).
