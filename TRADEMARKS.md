# The ECCE name

The software in this repository is free under the Educational Community
License 2.0 (see [`LICENSE`](LICENSE)). The licence covers the code. It does
not cover the name: section 6 of the licence says it grants no permission to
use the licensor's names. This page says how the name "ECCE" (Extensible
Computational Chemistry Environment) may be used, so that people can tell
this project's releases from other software. The name is not registered as a
trade mark.

ECCE was developed at Pacific Northwest National Laboratory. Since 2018 this
project, FriendsofECCE, is where ECCE is developed and released; PNNL's ECCE
website pointed its users here when PNNL stopped supporting it.

**You may, without asking:**

- call unmodified builds of this repository's source "ECCE", including
  packages that only adapt it to a distribution or system (paths,
  dependencies, packaging fixes);
- say that your software, course, paper or service *uses* ECCE, is *based
  on* ECCE, or *works with* ECCE;
- use the name in teaching material, documentation, talks and papers;
- distribute registrations of further codes, scripts and settings for ECCE,
  and call them that.

**Please ask first before:**

- distributing a modified version, one with changes beyond packaging, under
  the name "ECCE". Use a different name for it instead, and say it is based
  on ECCE;
- using "ECCE", or a confusingly similar name, as the name of another
  program, product or service;
- suggesting that this project endorses or supports a product or service
  when it does not.

Questions, and requests for permission, go to the
[issue tracker](https://github.com/FriendsofECCE/ECCE/issues).
